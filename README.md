# Jamboree Education Business Case Study

A data-analysis and regression modeling case study using Jamboree's graduate-admission dataset. The notebook includes exploratory analysis, model evaluation, and recommendations.

## Files

- `Jamboree_Education_Business_Case_Study_Rahul_Sharma.ipynb` — analysis and modeling notebook
- `Jamboree_Admission.csv` — dataset used by the notebook

## Run

Use Python 3 and install Jupyter plus the notebook dependencies:

```bash
python -m pip install jupyter numpy pandas matplotlib seaborn scikit-learn scipy statsmodels
```

Start Jupyter, open the notebook, and run the cells. Keep `Jamboree_Admission.csv` in the same directory as the notebook.
